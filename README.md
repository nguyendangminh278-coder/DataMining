# Rossmann Store Sales — Data Mining Team 2

This repository archives the team's original analysis code for data preparation, EDA, Promo2 analysis, forecasting and explainable AI (xAI).

The Colab notebook covering **P07–P14, F01, D01, E01 and M01** is available [here](https://colab.research.google.com/drive/19K7REYOXk6DfUlXBEf50IWaSfo_a5GK6?hl=vi). It is also included in `notebooks/03_F01_Promo2_Analysis.ipynb` with saved outputs removed for GitHub.

## Important

- The project uses the [Rossmann Store Sales Kaggle dataset](https://www.kaggle.com/competitions/rossmann-store-sales).
- Large CSV datasets, model outputs and credentials are not committed. Download the datasets separately and place them under `data/raw/`.
- The notebooks come from separate project stages and may require paths to be adjusted. The packaged code has not been fully re-executed or independently validated.
- The GitHub publication is a code archive, not a claim of production-ready forecasting or causal identification.

Additional source attributions and setup instructions are under `docs/` and `data/`.
